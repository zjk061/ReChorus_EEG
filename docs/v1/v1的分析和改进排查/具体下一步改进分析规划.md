## 修订说明（2026-06-22）

阶段 2 ablation 中，实验 C（`use_history_eeg=0`）test AUC 最高（0.759），但**该配置不能作为 v1.1 主路线**：

- **项目约束**：历史 EEG 是核心创新点，生产模型必须保留 `history_eeg_310` 的编码与使用。
- **正确解读 C**：C 说明**当前 v1 的 EEG 接入方式**（310 维 → LayerNorm → Linear MLP，early concat 进 history step）在小数据上**引入噪声/过拟合**，不等于 EEG 信息本身无用。
- **性能目标（不设人工上限）**：在**始终保留 EEG** 的前提下，以**当前已观测到的最好指标为参照、持续向上突破**为方向——理想情形是在保留 EEG 时 **test AUC 超过全部现有 ablation（含 C 的 0.759）**，并缩小 dev→test gap。A/B/C/D 仅是阶段性对照点，**不是天花板**。
- **实验 D 的定位**：D 仅调整了 `emb_size`、`fusion_hidden`、`dropout`、`l2`、`lr` 等**超参数**，**未改变** History Transformer Encoder + Candidate-to-History Cross-Attention 的整体结构；过拟合缓解不能指望只靠缩参，后续需考虑**架构级简化或替换**（见 §3.5）及 **EEG–情绪步内对齐**（见 §3.3）。

实验 C 仅保留为**诊断对照**（`use_history_eeg=0`），用于量化「当前 EEG 编码带来的负增益」，不作为最终模型配置，**也不作为性能上限**。

```bash
import pandas as pd

from sklearn.metrics import roc_auc_score, f1_score

def analyze(path, phase):

    print(f"n={len(df)}, pos_rate={y.mean():.3f}, pCTR mean={p.mean():.3f}")

        f = f1_score(y, (p >= t).astype(int))
        if f > best_f1:
            best_f1, best_t = f, t
    print(f"best F1={best_f1:.4f} at threshold={best_t:.2f}")
```

## 阶段 1：代码准备（1 天，为 ablation 服务）

### 1.1 在模型中增加 2 个 ablation 参数

在 `src/models/general/EEG_DGCN_v1.py` 的 `parse_model_args` 中增加：

```python
parser.add_argument('--use_history', type=int, default=1,
                    help='1: use history branch; 0: static baseline')
parser.add_argument('--use_history_eeg', type=int, default=1,
                    help='1: encode history EEG; 0: zero EEG embedding')
```

在 `__init__` 中保存：

```python
self.use_history = args.use_history
self.use_history_eeg = args.use_history_eeg
```

在 `_encode_history` 开头加：

```python
if not self.use_history:
    return torch.zeros(batch_size, self.emb_size, device=self.device)
```

在 EEG 编码处改为：

```python
if not self.use_history_eeg:
    history_eeg_emb = torch.zeros(
        batch_size, seq_len, self.history_eeg_dim, device=self.device)
else:
    history_eeg_emb = self.history_eeg_encoder(history_eeg)
```

**说明：**

- `use_history=0` 时 history 分支输出全零，fusion MLP 仍保留第三路输入  
- 这是最小改动 ablation；若结果差异很大，已足够判断 history 有无增益  
- 若差异很小，再考虑做「两路 fusion」的 static 版本


```
  → 当前 EEG 编码有效，可在此基础上微调
```

## 阶段 3：保留 EEG 的性能改进路线（第 3–7 天，当前重点）

> **前置：** 阶段 0–2 已完成。Ablation 已确认 history（item / label / emotion）有增益；当前 MLP 式 EEG 编码拖累性能。  
> **硬约束：** 所有 v1.1 实验 `--use_history 1 --use_history_eeg 1`（EEG 不可关）。实验 C 仅作对照，不参与模型选型。

只走**一条**主路线：**超参正则 → EEG 编码升级 → EEG–情绪步内对齐 → 序列级交互 / 架构简化**。每步只改一个变量。

### 3.0 参照基准与性能目标

**阶段性参照（非上限）：**

| ID | 配置 | test AUC | 角色 |
|----|------|----------|------|
| A | full + MLP EEG | 0.667 | **EEG 保留模型的起点** |
| B | 无 history | 0.718 | 说明 history 有增益 |
| C | 无 EEG（诊断） | 0.759 | **阶段性最优对照**（无 EEG，不可作最终配置，**不作天花板**） |
| D | 超参缩小+强正则 + MLP EEG | 0.702 | **超参正则参照**（结构同 A，见下） |

**关于实验 D 的准确定义：**

D 与 A 共享同一套结构：`History Step Encoder → TransformerEncoder（self-attention）→ MultiheadAttention（cross-attention）→ Fusion MLP`。D 仅改动：

```text
emb_size: 64 → 32
fusion_hidden: 64 → 32
dropout: 0.2 → 0.4
l2: 1e-6 → 1e-4
lr: 1e-3 → 5e-4
```

因此 D **不是架构上的「小模型」**，而是**超参层面的容量与正则收紧**。若过拟合仍明显，必须在 §3.5 考虑**结构级调整**，并配合 §3.3 步内对齐。

**性能目标（尽力提升，不设人工封顶）：**

| 维度 | 理想方向 | 说明 |
|------|----------|------|
| **test AUC** | **尽可能高**；目标 **> 0.759**（在保留 EEG 时超过当前全部 ablation 最优） | 不以 C 为上限；每次实验与**历史最佳**比较 |
| dev AUC | 高且稳定 | 辅助判断拟合是否健康 |
| dev→test gap | **尽可能小** | 泛化质量的重要信号 |
| best epoch | 不宜过早见顶（如 epoch 1–3 即 best） | 结合早停判断过拟合节奏 |
| 参数量 / 结构复杂度 | 在性能提升前提下可控 | 架构简化是手段，不是放弃 EEG |

**记录方式：** 每次实验填写「相对 A 的 Δtest_AUC」「是否刷新历史最佳」；**不设「及格/目标/理想」三档封顶**，以刷新个人最佳为进展标志。

### 3.1 子路线 A：超参正则 + 保留 MLP EEG（低成本，先做）

在**不改变 Transformer + Cross-Attention 结构**的前提下，复用实验 D 已验证的超参思路；明确以 A 为对照、EEG 必须开启。

| 实验 | 脚本（待建） | 相对 A 的唯一改动 | 目的 |
|------|--------------|-------------------|------|
| E1 | `run_stage3_E1_small_reg_eeg.sh` | 同 D 超参：`emb_size=32`, `fusion_hidden=32`, `dropout=0.4`, `l2=1e-4`, `lr=5e-4` | 复现 D 在保留 EEG 下的 0.702，作为超参基线 |
| E2 | `run_stage3_E2_early_stop5.sh` | E1 + `--early_stop 5` | 抑制 epoch 3 后过拟合 |
| E3 | `run_stage3_E3_eeg_dropout.sh` | E1 + `--eeg_dropout 0.5`（模型侧为 EEG 分支单独加 dropout） | 仅加强 EEG 通路正则 |

**判定：**

- E1 刷新历史最佳 → 继续 E2/E3，同时并行 §3.2  
- E1 仅略优于 A、仍远低于 C → **不要继续堆超参**；优先 §3.2（EEG 编码）、§3.3（EEG–情绪对齐）或 §3.5（架构简化）  

### 3.2 子路线 B：升级历史 EEG 编码器（核心创新修复）

当前 v1 对 `history_eeg_310` 使用 `LayerNorm(310) → Linear(310, 32)`，丢失电极空间结构；v0 初始版对当前样本 EEG 使用 **DGCNN**（62 电极 × 5 频带，动态图卷积），这才是「EEG 创新」的技术载体。

**改进方向（按优先级，每次只启用一项）：**

| 实验 | 改动 | 实现要点 | 目的 |
|------|------|----------|------|
| F1 | **历史 step 级 DGCNN** | 复用 `CTRLightGCN.py` 中 `EEGDGCNNEncoder`；`history_eeg_310` reshape 为 `[B, L, 62, 5]`，逐步编码 | 恢复电极拓扑与动态图建模，替代扁平 MLP |
| F2 | **DGCNN + 强正则** | F1 + E1 超参 | 控制 DGCNN 参数量带来的过拟合 |
| F3 | **EEG 分支门控** | `history_eeg_emb * sigmoid(gate(x))`，gate 由 item/label/emotion 上下文产生 | 允许模型学习「何时信任 EEG」，而非硬去掉 |
| F4 | **残差式 EEG 融合** | history step = base(item+label+emotion) + α·eeg_emb，α 可学习或按 step 门控 | 避免 EEG 噪声主导 step 表示 |

**与 §3.3 的关系：** F3/F4 是步内融合的轻量变体；§3.3 H 系列专门解决 **EEG 与情绪评分的跨模态对齐**，优先级高于 F3/F4 的通用门控。

**代码改动位置：** `src/models/general/EEG_DGCN_v1.py` 的 `history_eeg_encoder` 及 `_encode_history` 内 concat 逻辑；新增 `--history_eeg_encoder {mlp,dgcnn}` 开关便于 ablation。

**判定：**

- F1 刷新历史最佳 → DGCNN 为 v1.1 默认 EEG 编码，进入 §3.3  
- F1 ≤ E1 但 F3/F4 有提升 → 保留 MLP/DGCNN + 门控/残差，并并行 §3.3

### 3.3 子路线 C：EEG–情绪步内对齐融合（H 系列）

> **动机：** 数据侧在同一步 `t` 上，`history_eeg_310[t]` 与 `history_interest/immersion/valence/arousal[t]` 已按**同一次历史观看**对齐；但模型侧各自独立编码后直接 `concat`，没有显式建立「生理信号 ↔ 主观情绪」的跨模态关系。  
> Ablation 中 C（有情绪、无 EEG）远高于 A（有情绪 + MLP EEG），提示：**情绪分已是强信号摘要，未经对齐的 EEG 易成冗余/噪声**。  
> 本路线在**保留 EEG** 的前提下，在每个 history step 内先做 EEG–情绪融合，再与 item/label 合并进入序列建模——这也是「EEG + 推荐」创新点的合理建模方式。

**与严格前置 CTR 的边界：**

- 只对**历史步**上的 `(history_eeg_310[t], history_emotion[t])` 做对齐；当前样本的 EEG/情绪仍禁止输入。  
- 不涉及数据索引错位问题；要解决的是**表征空间与融合结构**。

**当前 v1 做法（待替换）：**

```text
eeg_emb = EEG_MLP(history_eeg_310[t])      # [eeg_dim]
emo_emb = Emotion_MLP(history_emotion[t])  # [emo_dim]
step_in = concat(item_emb, label_emb, eeg_emb, emo_emb)  # 隐式对齐
```

**目标做法：** 在同一步内显式融合后再拼 item/label：

```text
aligned_eeg_emo = Align(eeg_emb, emo_emb)   # 步内跨模态对齐
step_in = concat(item_emb, label_emb, aligned_eeg_emo)
```

**实现开关（建议）：**

```text
--eeg_emotion_fusion {concat, emo_gate, cross_attn, bilinear, co_attn, residual}
--align_loss_weight 0.0   # H4 专用，默认 0 即不加辅助损失
```

| 实验 | 脚本（待建） | 融合方式 | 实现要点 | 目的 |
|------|--------------|----------|----------|------|
| H1 | `run_stage3_H1_emo_gate.sh` | **情绪门控 EEG** | `eeg_emb * sigmoid(Linear(emo_emb))`；emo 不变或 concat 门控后 eeg | 最低成本：让情绪决定「该步 EEG 信多少」 |
| H2 | `run_stage3_H2_eeg_query_emo.sh` | **EEG query → 情绪** | 单步 `MultiheadAttention(query=eeg_emb, kv=emo_emb)` → `aligned` | 显式「用脑电查主观感受」 |
| H3 | `run_stage3_H3_co_attn.sh` | **双向 co-attention** | EEG↔Emotion 各做一次 cross-attn，concat 或相加 | 双向校准，强于单向 |
| H4 | `run_stage3_H4_align_loss.sh` | **H2 + 辅助对齐损失** | 同一步 `proj(eeg_emb)` 与 `proj(emo_emb)` 做 cosine/MSE，`align_loss_weight=0.01~0.1` | 给 EEG 分支明确「与同 step 情绪一致」的训练信号 |
| H5 | `run_stage3_H5_bilinear.sh` | **双线性融合** | `Bilinear(eeg_dim, emo_dim) → fusion_dim` | 捕捉 EEG–情绪二阶交互 |
| H6 | `run_stage3_H6_dgcnn_emo_cross.sh` | **F1 + H2 组合** | DGCNN 编码 EEG + 步内 cross-attn 对齐情绪 | 结构编码与跨模态对齐同时生效 |

**代码改动位置：**

- 新增 `_fuse_eeg_emotion(eeg_emb, emo_emb, mode)`，在 `_encode_history` 中于 `history_step_encoder` **之前**调用。  
- item/label 编码逻辑不变；仅替换 eeg/emo 进入 step 的方式。  
- H4 在 `forward` 或 runner 中累加辅助 loss（需记录日志项 `align_loss`）。

**实验纪律：**

- H1–H5 默认 **MLP EEG**（与 A 同编码器），只改融合，便于 isolate 对齐收益。  
- H6 在 H2/H3 优胜者确定后再跑，**不要与 H1–H5 同时改 DGCNN**。  
- 每次只改 `--eeg_emotion_fusion`（及 H4 的 loss 权重）一个变量。

**判定：**

- 任一 H 配置在**保留 EEG** 下刷新历史最佳 → 定为默认步内融合，再与 F1/F2（DGCNN）组合  
- H 系列整体仍低于 A → 优先检查 EEG 归一化（§3.6 J 系列）与 DGCNN（§3.2），再回头调 H4 损失权重  
- H6 刷新最佳 → v1.1 候选：**DGCNN + 步内 EEG–情绪 cross-attn**

**论文叙事要点（供写作）：**

- 数据：同一步观看的 EEG（过程中）与问卷情绪（观看后）在索引上对齐。  
- 模型：步内跨模态融合，使 EEG 作为情绪的**生理补充**而非与情绪**竞争输入**。

---

### 3.4 子路线 D：改进 EEG 与历史序列的交互方式（G 系列）

当前 EEG 在 history step 内 early concat，经 Transformer 与 cross-attention 混合；需在**更好 EEG 表示**基础上探索专门交互。

| 实验 | 改动 | 目的 |
|------|------|------|
| G1 | **双路 cross-attention**：一路对 item+label+emotion history，一路对 EEG-enriched history，再融合 | 让 EEG 有独立注意力通路 |
| G2 | **EEG 状态向量**：对 history EEG 序列单独 Transformer/GRU → `eeg_state_repr`，与 `candidate_aware_history` concat 进 fusion | 显式建模「用户脑电状态轨迹」 |
| G3 | **候选 item 对 EEG 历史的 cross-attention** | EEG step 单独做一轮 cross-attn |

**前置：** §3.2 或 §3.3 中至少有一组配置刷新历史最佳后再进入；G 系列改的是**序列级**交互，与 H 系列**步内**对齐正交（可组合，但不要同一次 run 同时 debut）。

---

### 3.5 子路线 E：历史建模**架构级**调整（I 系列，与超参 D 区分）

> **动机：** 实验 D（及 E 系列）只缩小 embedding / 加大 dropout / 调 lr/l2，**双层注意力结构原封不动**（Transformer self-attention + cross-attention）。在小数据（2487 train、30 用户）上，过拟合很可能来自**结构容量与归纳偏置不匹配**，需要真正的架构实验。

**原则：** 保留 EEG 编码与使用；每次只替换或简化**一个**历史建模组件，与 E/F 系列对照。

| 实验 | 架构改动 | 相对当前 v1 的变化 | 目的 |
|------|----------|-------------------|------|
| I1 | **去掉 Transformer，保留 cross-attention** | Step Encoder → 直接 cross-attn（DIN 风格） | 减少一层 self-attention 参数与过拟合面 |
| I2 | **GRU/LSTM 替代 Transformer** | Step Encoder → GRU → cross-attn | 更轻的序列建模，参数量可控 |
| I3 | **去掉 cross-attention，保留 Transformer + masked mean pool** | 仅 self-attn + pooling | 检验候选感知 cross-attn 是否必要 |
| I4 | **缩短有效历史** | `history_max: 50 → 20`（结构不变） | 降低序列长度带来的 attention 容量 |
| I5 | **减注意力头 / 减 FFN** | `num_heads: 4→2`，`dim_feedforward` 缩小 | 在保留双注意力框架下压缩子模块 |
| I6 | **轻量融合** | 历史侧只保留一种注意力（I1 或 I3 的优胜者）+ 更浅 fusion MLP | 端到端减负 |

**实现建议：** 新增 `--history_encoder {transformer,gru,none}`、`--history_pooling {cross_attn,mean}` 等开关，或 fork `EEG_DGCN_v1_lite.py`，避免与 E/F 改动纠缠。

**判定：**

- 某 I 系列配置在**保留 EEG** 下 test AUC **超过 C（0.759）** → 作为 v1.1 结构候选  
- 架构简化后 AUC 下降但 dev-test gap 明显缩小 → 与 §3.2 EEG 编码 + §3.3 步内对齐组合再试
