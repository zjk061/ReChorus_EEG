### 3.0 参照基准与性能目标

**阶段性参照（阶段 0–3，非上限）：**

| ID | 配置 | test AUC | 角色 |
|----|------|----------|------|
| A | full + MLP + concat | 0.667 | 原始起点 |
| C | 无 EEG（诊断） | 0.759 | 不可作最终配置 |
| E1 | MLP + concat + 强正则 | 0.702 | MLP 超参最优 |
| F1 | DGCNN + concat | 0.735 | DGCNN 单独有效 |
| H2 | MLP + cross_attn | 0.753 | 步内对齐备选 |
| **H5** | **MLP + bilinear** | **0.779** | **v1.1 首选 ✅** |

**H5 关键指标（best epoch = 1）：**

| 指标 | Dev | Test |
|------|-----|------|
| AUC | 0.762 | **0.779** |
| LOG_LOSS | 0.534 | 0.515 |
| dev→test gap | — | **−0.017**（test > dev） |

**性能目标（2026-06-25 修订）：**

| 维度 | 目标 | 说明 |
|------|------|------|
| **test AUC** | **≥ 0.779**（刷新 H5） | 主决策指标 |
| dev→test gap | 尽可能小 | 辅助；但「gap 缩小」不得牺牲 test（E3/H4 教训） |
| best epoch | 尽量 **> 1** 且 dev 曲线更稳 | 过拟合仍明显，属优化方向而非否决 H5 的依据 |
| 结构复杂度 | 在 test 不下降前提下可控 | I 系列服务于 ablation + 稳定性，非「必须先砍架构才能用好 EEG」 |

**过拟合现状（客观承认）：**

- H5 及多数实验 **best epoch 在 1–3**，之后 dev AUC/LOG_LOSS 恶化、train loss 继续下降——**过拟合仍然明显**。
- 但 H5 在 early checkpoint 上 **test 最优**；单纯减容量（D/E3/H4/H7）常使 dev 更好看、test 更差。
- 因此：**过拟合需要继续处理**，但手段应优先 **H5 上的超参微调（阶段 5）** 与 **轻量结构 ablation（I4/I5）**，而非大规模砍掉 Transformer/cross-attn。

**记录方式：** 每次实验填写「Δ vs H5」「Δ vs A」「是否刷新 EEG 保留最佳」；用 `scripts/analyze_stage3_experiment.py` 解析日志。

### 3.5 子路线 E：历史建模架构调整（I 系列，⏳ 待做，2026-06-25 修订）

> **动机（保留）：** 训练日志普遍 **best epoch 很早、dev 迅速恶化、train loss 继续下降**，过拟合仍然明显。  
> **动机（修正）：** H5 已在**完整双层 attention** 下达到 test 0.779；说明「必须先砍历史架构才能用好 EEG / 超过 C」的假设**不成立**。I 系列目标从「冲 0.759 的主攻」调整为：
>
> 1. **在 H5 底座上**验证 Transformer / cross-attn 是否必要（论文 ablation）  
> 2. **在 test ≥ 0.77 前提下**尝试减轻 early peak、稳定 dev 曲线（I4/I5 + 阶段 5）  
> 3. **避免**为 dev 好看而牺牲 test（E3/H4/H7 教训）

**硬性前提（与旧版不同）：**

- 所有 I 实验 **固定 H5 步内融合**（MLP + bilinear），不得用 concat 底座  
- 对照基准 = **H5（test 0.779）**，不是 C（0.759）或 A（0.667）  
- `--use_history 1 --use_history_eeg 1` 不变  

| 实验 | 架构改动 | 优先级 | 目的 |
|------|----------|--------|------|
| **I4** | `history_max: 50 → 20` | **高** | 降序列 attention 容量，成本低 |
| **I5** | `num_heads: 4→2`，缩小 FFN | **高** | 精准压缩 attention，可与阶段 5 合并 |
| **I3** | 去 cross-attn，Transformer + mean pool | **中** | 验证「候选感知 cross-attn」必要性（论文） |
| I1 | 去 Transformer，保留 cross-attn（DIN 风格） | 低 | 结构 ablation；预期 test ≤ H5 |
| I2 | GRU 替代 Transformer | 低 | 探索轻量序列编码；ROI 不确定 |
| I6 | I1/I3 优胜者 + 更浅 fusion MLP | 待定 | 仅 I3/I1 有结论后再定 |

**实现建议：**

```text
--history_encoder {transformer, gru, none}   # I1/I2
--history_pooling {cross_attn, mean}         # I3
# I4/I5 仅改现有超参，无需新模块时可先写脚本
```

脚本命名建议：`run_stage3_I3_h5_mean_pool.sh` 等，目录 `阶段3.5_历史架构ablation/`（待建）。

**判定（2026-06-25 修订）：**

| 结果 | 解读 | 行动 |
|------|------|------|
| test AUC **≥ 0.779** 且 best epoch 更晚 | 理想：性能不降、训练更稳 | 更新 v1.1 默认 |
| test AUC ≥ 0.77 且 gap 明显缩小 | 可接受的稳定性变体 | 写入论文/附录 |
| test AUC **< 0.77** | 结构 ablation 负面结果 | **仍是有价值的论文结论**（如 I3 证明 cross-attn 必要） |
| dev↑ test↓ | 过拟合缓解失败 | 停止该方向（同 H4/E3） |

**不建议：** 在未固定 H5 bilinear 的情况下跑 I 系列；不宜将 I1/I2 作为「冲性能」首选。

| l2 | 1e-6, 1e-5, 1e-4 | 与 E1 对照 |

**可选（若上述无增益）：**

| 参数 | 候选值 |
|------|--------|
| eeg_dropout | 0.2, 0.3（**不超过 0.4**，E3 教训） |
| early_stop | 5, 10 |

**选模规则：**

1. **test AUC 最高** 者为最终 v1.1  
2. 若多个配置 test 差 < 0.01，选 **dev→test gap 最小** 者  
3. **不得** 仅因 best epoch 更晚而选 test 更低的配置  

**成功标准（修订）：**

- **理想：** test **> 0.779** 且 best epoch > 1  
- **可接受：** test ≥ 0.779 且 LOG_LOSS / gap 改善  
- **失败：** test < 0.77 → 回退 H5 原配置，转 I4/I5 或 J 系列
