# 阶段 M 实施报告

实施日期：2026-07-03。

## 1. 实施范围和数据边界

本次实现了 M1–M4，并完成 Gate M 要求的 5 种子比较。M5 所需的原始视频、音频或已提取的
CLIP/VideoMAE/AST 特征在当前仓库中不存在，因此按方案标记为阻塞；这不影响以现有
`item_meta + video_type` 完成低级内容塔。

所有实验只使用协议 A 的 `2491 train / 357 dev`。统一加载器在排序、metadata join、历史构造
之前丢弃 710 条 `v2_locked_legacy_test`，本阶段没有输出任何 test 指标。

## 2. 具体实现

### 2.1 M1：独立的 v2 骨架

新增 `src/models/general/EEGStateLike_v2.py`，没有修改 v1 模型。该骨架不含 EEG 参数，
`use_maes=False` 时历史 MAES 四维也会被置零，因此能形成 EEG 和 MAES 同时关闭的严格共享
架构。模型输出 raw logits，训练使用 `BCEWithLogitsLoss`。

### 2.2 M2：cold-item 安全的共享内容塔

候选和历史 item 都由同一个 `SharedContentTower` 实例编码，输入是 17 维 item_meta 和
train-only one-hot 的 video type。正式默认 `content_only` 不创建 item embedding 参数，故 unseen
item 不会读取随机未训练 ID。

代码同时保留 `content_plus_seen_id` 和 `random_unseen_id` 两个显式诊断开关。前者把未见 item
映射到固定零向量；后者故意给全体 item 分配随机表，仅用于证明 cold-ID 问题，运行器不会把它
作为默认候选。

### 2.3 M3：可审计的加法 logit

最终 logit 严格由以下五项相加：

```text
global_bias + regularized_user_bias + user_meta_score
+ candidate_content_score + history_candidate_score
```

用户偏置单独使用零初始化 embedding，并在 AdamW 之外增加显式 L2；用户静态信息走独立线性
head。每个实验保存 `logit_components.csv`，配置中记录各项 mean/std/min/max/mean_abs。最佳配置
seed 0 的 user-bias mean_abs 为 0.0355，明显低于 candidate-content 的 1.5236 和 history-candidate
的 0.2750，没有出现 user-ID 项独占 logit 的现象。

### 2.4 M4：三种小型历史编码器

实现 masked mean、hidden size 24 的 time-aware GRU、候选感知 DIN attention。每个历史 step
包含共享 item 内容、历史 label、固定 `(MAES-1)/4`、历史观看时长、playrate、时间间隔、
session mode、video order 和 session position。padding 通过长度 mask 排除，历史只取最近 N 条。

三类编码器都比较了 N=10/20/30；早停只看 dev GAUC。训练使用 AdamW、梯度裁剪 1.0，所有
scaler/one-hot 只在 train 拟合。

### 2.5 运行和产物治理

新增 `src/baselines/stage_m.py` 和 `src/scripts/v2/run_stage_m_backbone.py`。每次运行落盘
`config.json`、`metrics.json`、`predictions.csv`、`per_user_metrics.csv`、`checkpoint.pt`、
`logit_components.csv`、`train.log` 和 `environment.txt`。汇总对五种子平均预测执行 1000 次
用户簇 bootstrap。

## 4. Gate M 判定

- cold-item 条件：通过。正式九个配置全部为 `content_only`，不存在 item-ID 参数。
- 五种子 GAUC 条件：未通过。最佳 M 模型 0.5501，低于阶段 B 最佳强基线
  `LR-content-only` 的 0.5854，差值为 -0.0353。
- 参数量和校准：工程上可接受，最佳配置只有 1,573 参数，平均 ECE 0.0774。
- 共享骨架：代码结构已形成，但由于数值门槛未通过，当前不能把它冻结为后续 EEG 实验的
  “唯一晋级骨架”，也不能进入阶段 G 并宣称 EEG 增益。

因此，本阶段的工程实现和正式实验均已完成，但研究决策 `Gate M = false`。下一步应只在 dev/
rolling validation 内处理非 EEG 主干的稳定性和内容表示，不得访问 locked test，也不得以增加
EEG 复杂度绕过该门槛。
