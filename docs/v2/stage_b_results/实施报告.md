# 阶段 B 实施报告

实施日期：2026-07-03。

## 1. 实施边界

本次完整实现执行方案 B1–B5。所有模型共享协议 A 的 `2491 train / 357 dev`、
相同的时点可用性规则和 `src/utils/like_metrics.py` 评价器。锁定的 710 条
`v2_locked_legacy_test` 在读入统一事件文件后立即按 manifest 丢弃，不进入排序、特征构造、

## 2. 具体实现

### 2.1 统一特征与历史

`src/baselines/stage_b.py` 建立统一入口，并从 `events.csv` 只读取非 EEG 必要列。事件按
`user_id, start_time, source_order` 稳定排序。当前输入分为四组：

- user：用户 ID、性别、年龄、短视频使用年限；
- content：17 个静态 item 内容特征，不包含 `item_id` embedding；
- context：session mode、video type、顺序、位置、时间间隔、新 session 标志和时刻周期；
- history：严格 `shift(1)` 后的累计/最近 5 条/最近 20 条点赞率，以及历史观看、播放率和
  MAES 统计。

当前事件的 `label/view_duration/playrate/MAES/EEG` 不属于任何当前特征。对 DIN/GRU，
这些字段仅在事件成为严格历史后进入最近 20 条序列；padding 由显式长度屏蔽。所有
StandardScaler/OneHotEncoder 仅在 train 上拟合。

### 2.2 B1：无学习和偏置基线

实现了全局点赞率（Beta(1,1) 平滑）、训练期用户点赞率（Beta(1,1) 平滑）、正则用户
偏置，以及用户偏置 + session mode + video type。后两者用带 L2 的 logistic bias 模型，
保持概率目标和正则含义明确。

### 2.3 B2：Logistic Regression

实现 `LR-user-only`、`LR-content-only`、`LR-history-only` 和 `LR-all`。类别特征 train-only
one-hot，连续特征 train-only z-score，统一使用 `C=0.1` 的 L2 Logistic Regression。

### 2.4 B3：树模型

使用项目已有 scikit-learn 的 `HistGradientBoostingClassifier`，没有增加依赖。为小数据设置
`max_depth=4`、`max_leaf_nodes=15`、`min_samples_leaf=20`、`l2_regularization=1.0`，
避免通过无限制树深过拟合 dev。

### 2.5 B4：框架内深度基线

`src/baselines/stage_b_deep.py` 实现共享 v2 特征契约的小型 FM、DeepFM、DCNv2、无 EEG
DIN 和无 EEG time-aware GRU。深度模型均输出 raw logits，使用 `BCEWithLogitsLoss`、
AdamW、梯度裁剪 1.0，并只按 dev GAUC 早停。DIN 对候选静态内容与历史内容做 attention；
GRU 对历史内容、已发生行为和时间间隔编码。五个模型均不读取 EEG。

### 2.6 B5：实验治理和汇总

`src/scripts/v2/run_stage_b_baselines.py` 固定运行 5 个种子。每次实验落盘阶段 E 标准
`predictions.csv`、完整 `metrics.json`、`per_user_metrics.csv`、`config.json`、
`environment.txt` 和 `train.log`。统一表记录参数量、最佳 epoch、运行时间和全部 dev 指标。
每模型对五种子平均预测做 1000 次用户簇 bootstrap，而不是逐样本 bootstrap。

## 4. 结论和 Gate B 判定

最佳简单基线是 `LR-content-only`，最佳非 EEG 深度基线是 `DeepFM`。Global AUC 与 GAUC
排名明显冲突：仅用户倾向就能得到约 0.71–0.74 Global AUC，却没有用户内排序能力；
`LR-all` 的 Global AUC 最高但 GAUC 低于随机水平。反过来，content-only LR 的 GAUC
最高，但由于没有利用用户间点赞率差异，Global AUC 只有 0.5792。

五种子平均预测的用户簇 bootstrap GAUC 95% CI 分别为：`LR-content-only`
`[0.4956, 0.6685]`、`DeepFM` `[0.4504, 0.6471]`。区间较宽且高度重叠，说明 20 个用户的
小样本不足以支持“LR 显著优于 DeepFM”的强结论；这里的“最佳”只是按预先规定的 dev
点估计排序。

因此，阶段 B 的“统一基线表”交付已经完成，但复杂深度基线尚未超过最佳 LR。按照执行
方案的 Gate B，当前**不能用增加 EEG 复杂度绕过该结果**。已完成的排查表明：

- 特征侧有自动化测试确认当前后验、EEG 和 cold item ID 不会进入输入；
- 损失侧深度模型统一使用稳定的 raw-logit BCE，未发现 NaN/Inf；
- 评价侧所有预测走阶段 E 同一评价器，AUC/GAUC 冲突是实测结果而非混用口径；
- 最值得在进入 EEG 前继续处理的是小样本深度模型方差、历史特征的时间漂移，以及仅按
  单个 dev 窗口早停带来的不稳定性。

也就是说，代码与实验基础设施已经通过 Gate B 的完整性要求；研究决策门槛则要求先让
非 EEG 深度主干稳定达到或超过 `LR-content-only`，再进入阶段 M/G。
