## 4. 下一步 V2-E

下一步不建议继续盲目扩大模型。应做受控修复：优先围绕 fold1/fold3 的用户样本结构和 EEG sensitivity，尝试 listwise loss、hard-negative 比例/采样覆盖搜索、EEG 多尺度特征稳定化，以及按用户样本量加权的训练策略。若诊断 oracle 仍无法接近 `0.8`，应重新审视数据、任务定义或当前 rolling 协议下的理论可达性。
