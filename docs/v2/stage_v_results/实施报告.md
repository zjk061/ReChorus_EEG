# 阶段 V1 实施报告

## 1. 执行结论

阶段 U+ / V1 已完成首轮正式运行。所有实验仍使用 `protocol_a_rollv2_cv3` rolling-CV train/dev，未访问 `v2_locked_legacy_test`。

V1 的目标是以 `U2-profile-gated` 为当前新基准，继续尝试更强的 EEG 利用结构。结果显示：

- V1 找到了 AUC 更高的 EEG 候选。
- 最高 AUC 候选为 `V1-profile-dynamic-gated_cross_attention`，mean GAUC `0.616020`，Macro User AUC `0.619353`，Global AUC `0.654840`。
- 它高于 `U2-profile-gated` 的 mean GAUC `0.611574`，相对提升 `+0.004447`。
- 按用户最新规则，模型好坏只看 AUC 类核心指标；LogLoss、Brier、ECE 只记录为审计信息，不再阻断晋级。

因此 V1 首轮最终动作是：

```text
freeze_stage_v_candidate::V1-profile-dynamic-gated_cross_attention
```

也就是说，当前正式最佳 AUC 模型已经更新为：

```text
V1-profile-dynamic-gated_cross_attention
```

下一轮冲高线索也非常明确：围绕 `V1-profile-dynamic-gated_cross_attention` 和 `V1-profile-dynamic-gated` 做多种子确认、线性 ensemble 和受控结构微调。

## 3. 工程实现

本轮新增能力：

- 在 `src/baselines/stage_u.py` 中新增 `gated_cross_attention` 交互结构。
- 在 `stage_u_development_configs("v1")` 中注册 V1 首轮四个候选。
- 在 `src/scripts/v2/run_stage_u.py` 中支持 `--suite v1`，默认输出到 `docs/v2/stage_v_results` 和 `log/v2/stage_v`。
- V 阶段决策逻辑已改为 AUC-only：候选必须超过 Stage-U incumbent 或当前冠军 GAUC 才能替换当前最佳模型；校准指标只记录不阻断。

正式运行命令：

```text
.\.venv\Scripts\python.exe src\scripts\v2\run_stage_u.py --suite v1 --seeds 0 1 2 --device cpu --resume --bootstrap 0
```

## 4. 下一步

V2 不应继续盲目扩结构，而应围绕当前 AUC 冠军做可复现冲高：

1. 对 `V1-profile-dynamic-gated_cross_attention` 做 5 seeds 确认，核对 GAUC、Macro User AUC、Global AUC 是否稳定。
2. 尝试 `V1-profile-dynamic-gated_cross_attention`、`V1-profile-dynamic-gated` 与 `U2-profile-gated` 的 seed/model ensemble。
3. 基于 out-of-fold 预测训练线性 Logistic/Ridge AUC blender，不使用 locked test。
4. 小范围微调当前冠军附近结构，包括 gate 强度、cross-attention residual scale、profile/dynamic dropout 和学习率。
5. V2 晋级标准只看 AUC 类核心指标是否超过当前冠军，同时必须保留 H2/E0、zero、causal shuffle 对照与 EEG sensitivity 审计。
