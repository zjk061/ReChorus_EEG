## 5. 解释边界

V2-H 的局部排序结果不能直接替代原 rolling like 二分类正式冠军。只有回迁到原 rolling dev 后的 GAUC、Macro User AUC 和 Global AUC 才能用于判断是否产生原协议候选升级。

当前仍不得访问 locked test；若没有超过当前冠军 `0.616020`，则不能声称产生新冠军或达到 `0.8`。
