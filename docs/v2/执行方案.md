# EEG-SVRec v2 项目完整执行方案

## 1. 文档用途

本文档是项目后续开发、实验和决策的唯一执行路线图。`改进分析方案规划.md` 负责解释“为什么要改”，本文负责规定“先做什么、改哪些文件、产出什么、如何验收、何时停止”。

后续讨论统一使用本文任务编号，例如：

```text
D1：建立唯一数据源
E2：实现 GAUC 与用户级 bootstrap
B3：训练 Logistic Regression 强基线
M2：建立共享内容塔
G4：完成 EEG shuffled 消融
```

任何会改变任务定义、数据切分、主指标或 locked test 的决定，都必须先更新本文，再修改代码或运行正式实验。

## 2. 已冻结的项目定义

### 2.1 预测任务

最终任务固定为：

> 在候选视频开始播放前，利用当时已经可获得的信息，预测用户是否会点赞该视频。

`label=1` 表示真实点赞，`label=0` 表示视频已曝光并被观看但没有点赞。负样本不是人工采样。

### 2.2 推理时可用信息

预测视频 `t` 时允许使用：

- 用户静态信息：用户 ID、性别、年龄、短视频使用年限。
- 当前候选视频的静态内容特征、视频来源类型及推荐前已确定的 session 上下文。
- 视频 `t-1` 及更早历史中的 item、点赞、观看行为、MAES、EEG、时间间隔、session 和顺序信息。

系统假设用户佩戴 EEG 设备，并且每看完一个视频就能在下一视频播放前立即获得该视频的 EEG 和 MAES。因此，同一 session 内前序视频的 EEG 和 MAES 可以作为历史输入。

预测视频 `t` 时禁止使用：

- 视频 `t` 的 EEG、MAES、观看时长、播放比例、结束时间和点赞结果。
- 视频 `t+1` 及之后的任何信息。

### 2.3 当前明确暂不处理的事项

- 官方310维平均EEG在发布前使用参与者全周期秒级特征拟合 Min-Max 的问题，当前按用户要求暂时忽略。
- 不重新定义官方五频带范围；beta 与 gamma 的25–30 Hz重叠按官方数据保留。
- 不在基础评估、数据和强基线完成前继续扩大 DGCNN、Transformer 或融合模块。
- 不删除或覆盖 `EEG_DGCN_v1.py`、现有 strict 数据和历史实验脚本；v2 使用新文件和新目录开发。

## 3. 总目标与成功标准

项目目标不是单独提高一次 Global AUC，而是建立可信、可复现、对冷 item 有效，并能证明 EEG 独立贡献的视频播放前点赞预测系统。

### 3.1 主指标

模型选择和早停主指标：

1. GAUC：按用户样本量加权的用户内 AUC。
2. Macro User AUC：每个有效用户 AUC 的算术平均。

辅助指标：

- Global AUC。
- LogLoss。
- Brier Score。
- ECE。
- 用户级 bootstrap 置信区间。
- seen-item、unseen-item、session mode、video type 分层指标。

ACC 和 F1 只作为阈值相关参考，不作为模型晋级依据。

### 3.2 最终模型晋级条件

最终候选模型至少满足：

- 在完全相同协议下，5个随机种子的平均 GAUC 高于所有强基线。
- 至少4/5个种子优于最佳非EEG基线，且结果没有依赖单一异常种子。
- unseen-item 子集没有因随机 item embedding 造成明显退化。
- LogLoss、Brier 和 ECE 不出现不可接受的校准恶化。
- 真实 EEG 稳定优于无 EEG、零 EEG 和用户内 shuffled EEG；否则不得宣称 EEG 有效。
- 所有正式结果可由固定配置、数据版本和随机种子复现。

理想证据是用户级 cluster bootstrap 的 `ΔGAUC` 95%置信区间下界大于0。若受小样本限制区间仍跨0，必须如实报告不确定性，不得只依据单次最高值下结论。


- 当前样本后验字段不进入当前输入。

### D3. 补充时间和session特征

## 7. 阶段 E：重建评价和test隔离

### E1. 修复CTRRunner基础问题

修改或新建v2 Runner，优先建议新建：

```text
src/helpers/LikePredictionRunner.py
```

必须修复当前 `CTRRunner` 在显式传入 `--main_metric` 时仍引用 `self.main_metric` 的错误，应正确读取 `args.main_metric`。

训练脚本必须支持：

- `--main_metric GAUC`。
- `--eval_test 0`，开发训练结束后不自动评估test。
- 只按dev主指标保存checkpoint和早停。
- `--test_epoch -1` 作为强制默认值。

### E2. 实现完整指标

新增统一评价模块，例如：

```text
src/utils/like_metrics.py
```

实现：

- Global AUC。
- GAUC。
- Macro User AUC。
- LogLoss。
- Brier Score。
- ECE，固定bin规则并记录bin数。
- ACC/F1，仅辅助。

GAUC和Macro AUC只统计同时包含正负样本的用户，并同时报告：

- 有效用户数。
- 被排除用户数及原因。
- GAUC权重定义。

### E3. 用户级cluster bootstrap

以用户为抽样单位有放回抽样，而不是逐样本bootstrap。固定随机种子，默认1000或2000次，输出：

- 单模型指标95%置信区间。
- 两模型配对 `ΔGAUC/ΔAUC/ΔLogLoss` 置信区间。
- bootstrap失败次数和有效次数。

### E4. 分层评估与预测落盘

每次评估保存：

```text
event_id,user_id,item_id,time,label,prediction,
seen_item,session_mode,video_type,history_length
```

自动生成：

- seen-item/unseen-item指标。
- 各session mode、video type指标。
- 按历史长度分桶指标。
- 每用户 AUC、样本数、点赞率。

### E5. 评价器单元测试

使用人工小数组验证：

- AUC、GAUC、Macro AUC手算一致。
- 单类别用户处理正确。
- 样本顺序变化不影响指标。
- bootstrap以用户簇为单位。
- ECE边界值0和1处理正确。
- 显式 `--main_metric GAUC` 能控制早停。

### Gate E

同一份v1预测必须能稳定复算出已有Global AUC，并额外得到GAUC、Macro AUC、Brier和ECE。训练过程中不得访问locked test。

## 8. 阶段 B：建立不可绕过的强基线

所有基线使用同一split、同一特征可用性和同一评价器。

### B1. 无学习和偏置基线

依次实现：

- 全局点赞率常数预测。
- 训练期用户点赞率，带Beta/Laplace平滑。
- global bias + regularized user bias。
- user bias + session mode/video type。

这些基线用于量化Global AUC中有多少来自用户总体点赞倾向。

### B2. Logistic Regression

特征分组：

- 用户静态特征。
- 候选静态item特征。
- session/video type/order/time。
- 历史累计与最近窗口统计。
- 不使用当前后验字段。

分别运行：

```text
LR-user-only
LR-content-only
LR-history-only
LR-all
```

### B3. 树模型

可选安装 CatBoost 或 LightGBM，若引入新依赖必须单独记录。至少完成一个树模型，并控制深度、叶子数和正则，避免小数据过拟合。

### B4. 框架内深度基线

运行并统一特征：

- FM/DeepFM。
- DCNv2。
- 不含EEG的小型DIN。
- 不含EEG的time-aware GRU。

### B5. 基线结果表

每个基线至少5个种子，报告 mean±std、用户级bootstrap CI和参数量。确定：

- 最佳简单基线。
- 最佳非EEG深度基线。
- Global AUC与GAUC排名是否冲突。

### Gate B

只有统一基线表完成后才开发v2主模型。若复杂深度基线不能超过LR/树模型，应先检查特征、损失和评价，不得通过增加EEG复杂度绕过该问题。

## 9. 阶段 M：建立面向冷item的非EEG主干

### M1. 新建v2模型，不修改v1

建议文件：

```text
src/models/general/EEGStateLike_v2.py
```

模型第一阶段必须支持完全关闭EEG和MAES，以便形成严格共享架构消融。

### M2. 候选与历史共享内容塔

候选和历史item使用同一个内容编码器：

```text
item_meta + video_type + 可选预训练多模态embedding
→ shared content tower
→ item_content_repr
```

首轮只用现有item_meta和video type。不得让未训练的cold-item ID embedding进入默认路径。

保留以下消融开关：

```text
content_only
content_plus_seen_id
random_unseen_id（仅用于证明问题，不作为候选模型）
```

### M3. 显式分离用户偏置和用户内偏好

输出logit采用可解释加法结构：

```text
logit = global_bias
      + regularized_user_bias
      + user_meta_score
      + candidate_content_score
      + history_candidate_score
```

分别记录各项logit分布，防止user embedding独占预测。

### M4. 小型候选感知历史模型

优先顺序：

1. masked mean，无序基线。
2. hidden size 16–32 的time-aware GRU。
3. 候选感知DIN attention。

每个历史step初始使用：

```text
历史item内容 + 历史label + 历史MAES
+ 历史观看行为 + time gap + session/order
```

首轮历史长度只比较10、20、30；不把50作为默认。选模依据GAUC而不是Global AUC。

### M5. 预训练视频内容特征

只有现有低级内容塔稳定后再做：

- CLIP关键帧embedding。
- VideoMAE视频动态embedding。
- AST音频embedding。

全部离线提取、保存版本、默认冻结，仅训练小投影层。若原始视频不可得，本任务标记为阻塞但不影响先完成现有item_meta内容塔。

### Gate M

非EEG主干必须：

- 在unseen-item上不依赖随机ID。
- 5种子平均GAUC至少达到或超过最佳强基线。
- 参数量、训练稳定性和校准可接受。
- 形成后续EEG实验唯一共享骨架。

## 10. 阶段 G：证明EEG是否真正有效

### G1. 先做简单EEG编码器

按顺序实现：

1. PCA/PLS降维基线。
2. 310维小型MLP。
3. 五频带独立MLP + channel attention。
4. 脑区聚合与左右半球差异。
5. 固定电极拓扑GCN。
6. 小型可学习邻接图。

首轮禁止直接上大型EEG Transformer。

### G2. EEG作为历史状态增量

推荐结构：

```text
eeg_state_t = EEGEncoder(eeg_t)
maes_state_t = MAESEncoder(maes_t)
gate_t = sigmoid(W[eeg_state_t, maes_state_t])
history_event_t = base_event_t + gate_t * eeg_state_t
user_state_{t+1} = GRU(user_state_t, history_event_t)
```

EEG只更新下一时刻用户状态，不允许连接当前候选视频的当前EEG。

### G3. 归一化消融

在相同模型上比较：

- global train z-score。
- subject train z-score。
- subject residual。
- session residual。

必须使用唯一训练事件统计，不能恢复累计历史重复计权。

### G4. EEG真实性消融矩阵

完全相同架构、参数规模和训练协议下运行：

| ID | 输入 |
|---|---|
| E0 | 无EEG |
| E1 | 真实EEG |
| E2 | 用户内打乱时间顺序的EEG |
| E3 | 跨用户打乱EEG |
| E4 | 仅用户EEG均值 |
| E5 | 去除用户均值后的EEG residual |
| E6 | 仅MAES |
| E7 | EEG + MAES |
| E8 | EEG置零但保留相同参数路径 |

shuffle映射必须由固定种子生成并保存，确保不同模型重复使用同一扰动。

### G5. 新用户泛化

对关键模型运行LOSO或GroupKFold：

- 无EEG主干。
- 真实EEG。
- shuffled EEG。
- EEG residual。

用于判断EEG是否只编码被试身份。

### Gate G

只有真实EEG在多种子GAUC上稳定优于E0、E2和E8，才能进入复杂EEG结构搜索并在结论中宣称EEG提供了时序增益。若不满足，则保留“EEG无可靠独立增益”的结论，主模型退回最佳非EEG版本。

## 11. 阶段 T：训练、损失和有限搜索

### T1. 改用raw logits

模型forward输出raw logits，训练使用：

```python
BCEWithLogitsLoss
```

评估时再sigmoid。验证新旧损失在相同logit下数值一致，并检查无NaN/Inf。

### T2. 优化器和稳定性

默认：

- AdamW。
- 梯度裁剪1.0或5.0。
- ReduceLROnPlateau或cosine scheduler。
- early stop依据dev GAUC。
- 参数量优先控制在3万–8万，超过时必须说明必要性。

### T3. 用户平衡

比较：

- 普通sample-level BCE。
- 按用户逆样本量加权。
- user-balanced batch sampler。

观察Global AUC、GAUC和校准之间的变化。

### T4. 同用户pairwise损失

在最佳BCE模型后再实验：

```text
Loss = BCEWithLogits + λ × same-user pairwise ranking loss
```

只在同一用户正负样本间构造pair。搜索少量 `λ`，例如0、0.05、0.1、0.2，不进行大规模网格搜索。

### T5. 随机种子和搜索预算

- 开发筛选：3个种子。
- 晋级确认：至少5个种子。
- 最终核心结论：条件允许时10个种子。
- 超参数只在dev/rolling validation搜索。
- 每一阶段只搜索少量有理论依据的参数，禁止在当前test上反复试验。

## 12. 阶段 A：高级模型探索

只有Gate G通过后才允许：

- 固定拓扑DGCNN/GCN精调。
- band/channel多级attention。
- 域对抗去除subject identity。
- 自监督EEG预训练。
- 轻量Transformer。

每个高级模型必须与相同参数预算的简单编码器比较，并保留E0/E2/E8消融。高级结构若只提升Global AUC、不提升GAUC，不晋级。

## 13. 阶段 F：最终确认和报告

### F1. 冻结候选

根据rolling validation选择：

- 最佳简单基线。
- 最佳非EEG模型。
- 最佳真实EEG模型。
- 必要的shuffled/zero消融。

冻结代码、配置、checkpoint规则和种子后，才允许访问 `v2_locked_legacy_test`。

### F2. 一次性locked test

统一运行并报告：

- GAUC、Macro User AUC、Global AUC。
- LogLoss、Brier、ECE。
- 用户级bootstrap CI和模型差值CI。
- seen/unseen item分层。
- session mode、video type、history length分层。
- 5或10种子mean±std。

不得根据locked test结果返回修改超参数。如果发现实现bug，可以修复后整体重跑，但必须在实验台账中记录原因，不能选择性保留更好结果。

### F3. 最终结论规则

- 非EEG模型最好：结论是内容和历史建模有效，EEG尚无可靠独立贡献。
- 真实EEG优于无EEG但不优于shuffle：结论是EEG主要提供用户身份或分布信息。
- 真实EEG稳定优于无EEG和shuffle：可以主张EEG提供时序认知状态增益。
- Global AUC升高但GAUC下降：不视为推荐能力提升。

## 15. 风险、停止规则和回退策略

### 15.1 小样本过拟合

表现：最佳epoch过早、种子方差大、train持续提升而dev下降。

措施：减小参数、加强正则、减少历史长度、使用简单模型、多种子和置信区间。不得通过报告单一最佳种子掩盖。

### 15.2 Global AUC假提升

表现：Global AUC提高但GAUC不变或下降。

措施：检查user bias占比、按用户指标和分层结果；模型不得晋级。

### 15.3 冷item随机表示

表现：unseen item仍经过未训练ID embedding。

措施：默认内容塔；ID仅在seen-item消融中使用；增加自动测试阻止随机cold ID进入正式模型。

### 15.4 EEG伪增益

表现：真实EEG与用户内shuffle、用户均值表现相同。

措施：结论降级，使用residual/LOSO验证；不继续堆复杂EEG结构。

### 15.5 数据入口漂移

表现：`data(eeg).csv`与旧版三分并集不一致。

措施：构建立即失败；不自动选择其中一套继续训练。

### 15.6 test再次变成验证集

表现：训练脚本自动打印test，或根据test选择模型。

措施：默认 `eval_test=0`；最终脚本与开发脚本分离；访问记录写入实验台账。
