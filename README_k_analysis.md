# DGCNN k值超参数分析指南

## 概述

本指南帮助你分析DGCNN模型中k值（KNN邻居数量）对模型性能的影响。k值控制着每个EEG电极节点选择多少个最相似的邻居来构建动态图结构。

## 文件说明

### 1. 修改后的模型文件
- `CTRLightGCN.py`: 已添加`--dgcnn_k`参数支持

### 2. 分析脚本
- `hyperparameter_analysis.py`: 完整的超参数分析脚本
- `quick_k_test.py`: 快速功能测试脚本
- `k_experiment_config.py`: 实验配置文件

## 推荐的k值设置

### 小k值 (4-8)
- **特点**: 稀疏连接，计算效率高
- **适用场景**: 计算资源受限，实时应用
- **预期效果**: 训练快，但可能信息不足

### 中等k值 (10-15)
- **特点**: 平衡连接密度和计算复杂度
- **适用场景**: 一般应用场景
- **预期效果**: 稳定的性能表现

### 大k值 (20-30)
- **特点**: 密集连接，信息丰富
- **适用场景**: 对精度要求高的场景
- **预期效果**: 更好的特征表示，但计算开销大

### 特殊k值
- **k=1**: 最小连接，每个节点只连接1个最相似邻居
- **k=62**: 全连接，每个节点连接所有其他节点

## 使用方法

### 1. 快速功能测试

```bash
# 测试不同k值的基本功能
python quick_k_test.py
```

这个脚本会快速测试k=4,6,8,10,12,15,20,25,30的效果，包括：
- 前向传播时间
- 参数数量
- 输出统计信息

### 2. 完整超参数分析

```bash
# 运行完整的超参数分析
python hyperparameter_analysis.py
```

这个脚本会：
- 自动运行所有k值的训练实验
- 收集性能指标（AUC, NDCG, Recall等）
- 生成分析报告

### 3. 手动单次实验

```bash
# 测试特定k值
python main.py --model CTRLightGCNCTR --dataset your_dataset --dgcnn_k 8 --epoch 50
```

## 实验配置

编辑 `k_experiment_config.py` 来配置实验：

```python
# 修改数据集名称
EXPERIMENT_CONFIG["dataset"] = "your_actual_dataset"

# 选择实验场景
scenario = "quick_validation"  # 或 "performance_comparison"
k_values = EXPERIMENT_SCENARIOS[scenario]["k_values"]
```

## 预期结果分析

### 性能趋势
1. **小k值**: 计算效率高，但可能欠拟合
2. **中等k值**: 平衡性能和效率
3. **大k值**: 信息丰富，但可能过拟合

### 计算复杂度
- k值越大，计算复杂度越高
- 内存使用量与k值成正比
- 训练时间随k值增加而增加

## 最佳实践建议

### 1. 实验策略
1. **快速验证**: 先用小k值(4-8)验证模型基本功能
2. **范围搜索**: 测试中等k值(10-15)找到平衡点
3. **精细调优**: 在最佳范围内进行精细搜索

### 2. 选择标准
- **计算资源充足**: 优先考虑k=15-25
- **实时应用**: 选择k=4-8
- **精度优先**: 选择k=20-30
- **平衡考虑**: 选择k=10-15

### 3. 注意事项
- 不同数据集可能需要不同的最佳k值
- 考虑模型复杂度与数据量的匹配
- 监控过拟合现象，特别是大k值情况

## 结果解读

### 成功指标
- AUC > 0.7 (推荐 > 0.8)
- 训练时间在可接受范围内
- 验证集性能稳定

### 警告信号
- 训练集性能远高于验证集（过拟合）
- 训练时间过长（k值过大）
- 性能随k值增加而下降（数据不足）

## 故障排除

### 常见问题
1. **内存不足**: 减小batch_size或k值
2. **训练过慢**: 减小k值或使用更少的epochs
3. **性能不佳**: 尝试更大的k值或调整其他超参数

### 调试建议
1. 先用小数据集快速验证
2. 逐步增加k值观察性能变化
3. 记录详细的实验日志
